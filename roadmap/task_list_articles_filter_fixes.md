# タスクリスト: フィルターパネルUIの改善と修正

1. `src/pages/articles/index.astro` の `filter-panel` クラスについて、固定時にヘッダーに重ならないように `top` を調整（例: `top: 6rem;`）する。
2. フィルターパネルのタイトルを「フィルター」から「絞り込んで検索」に変更する。
3. カテゴリーとタグのフィルター表示名の先頭に `#` を追加する。
4. 要素タグの表示領域が長くなった場合（4行以上）を想定し、CSSの `max-height` と `overflow: hidden` を活用した折りたたみ仕様を実装する。また、「全てのタグを表示」のトグルボタンを追加し、JSでクラスの切り替えを行う。
5. 年月検索のグループタイトルを「時間」から「公開日」に変更する。
