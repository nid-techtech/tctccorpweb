# タスクリスト: 記事内タグデザインの条件付きUI調整

1. `src/pages/articles/index.astro` の `.tag-link` の平常時（未選択かつ非ホバー状態）のCSSスタイルを、背景色/枠線なしの水色テキスト（旧デザイン基調）に変更する。
2. ホバー時またはアクティブ（URLクエリにより選択状態）時のみ、枠付き＋青色塗りつぶしのピル型デザインを適用する（`.tag-link.is-active` などを定義）。
3. `.tag-link` HTML要素に `data-type` と `data-name` 属性を追加し、フィルタリングの初期および変更タイミングのJSループ処理の中で、現在選択されているタグと一致するものについて `.is-active` クラスを動的に付け外しするよう機能追加する。
