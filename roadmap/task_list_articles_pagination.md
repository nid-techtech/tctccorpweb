# タスクリスト: 記事一覧へのクライアントサイド・ページネーション＆URL同期の実装

1. `src/pages/articles/index.astro` のスクリプトに対し、URLから現在のフィルター状態とページ番号を読み取る `restoreFiltersFromURL()` 関数を実装する。
2. フィルター関数 `applyFilters()` を改修し、即座にDOMを表示・非表示にするのではなく、マッチしたDOM要素の配列を生成する。
3. マッチした配列を元に、1ページあたり12件で分割し、現在のページ番号に該当する要素のみ `display: block` またはレイアウトに適したスタイルを適用する。
4. 動的にページネーション用のボタン群（1, 2, 3... 次へ/前へ）をHTMLツリー内にレンダリングし、イベントリスナーを追加する。
5. フィルタやページの変更があった際に `history.pushState` を用いてURLのクエリパラメータを更新する処理を追加する。
6. ブラウザの「戻る」「進む」ボタン（`popstate` イベント）に対応する処理を追加する。
7. ページネーションUIのためのCSSをスタイルを追記する。
