# タスクリスト: articlesページのフィルター機能追加

1. `src/pages/articles/index.astro` のレイアウトを2カラムに変更（左: 記事一覧、右: フィルター）。
2. メタデータ（カテゴリ、タグ、ライター、作成年月）を収集し、フィルター要素（チェックボックス、プルダウンなど）をレンダリングする。
3. 抽出条件:
    - カテゴリ: blog, works, info
    - タグ: カテゴリタグを除くすべてのタグ（記事数が多い順）
    - ライター: すべての author（記事数が多い順）
    - 年月: 2026年から現在までの年（未選択でなければ同列またはすぐ下に月を表示）
4. JavaScript (Astro の `<script>` タグ) を用いて、フィルター操作（変更・クリア等）で左側の記事一覧の表示/非表示を動的に切り替える仕組みを構築。
5. モバイル表示の対応: デフォルト非表示のフィルターパネルを用意し、ボタンクリックで展開するようにCSSとJSでトグル処理を実装する。
