# 記事内容（post-content）の構造統一化

- [x] **記事タイトルの高さ固定**: タイトル表示用に常に2行分のスペースを確保し（`min-height: 2.8em`）、3行以上に長くなる場合は末尾を `...` で省略する（`-webkit-line-clamp: 2`）スタイルを適用。
- [x] **メタデータのフォーマット統一**: `by [Author] on [created_at] | [文字数] 文字` の表示構成に変更。Authorがない場合はデフォルトで「TECH☆TECH」を適用。
- [x] **Descriptionの表示と省略**: Descriptionが存在する場合は1行のみ表示し、あふれる場合は `...` と丸める設定（`-webkit-line-clamp: 1`）を追加。
- [x] **タグの優先整理**: カテゴリタグ（`#blog`, `#works`, `#info`）とそれ以外の要素タグを分別し、常にカテゴリタグが先頭に並ぶようにレンダリング順序を変更。
